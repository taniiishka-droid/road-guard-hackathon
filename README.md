# road-guard-hackathon
A web application to report and track street-level road hazards.

Street-Level Civic & Road Hazard Tracker

About

RoadGuard is a web application that helps citizens report civic issues such as potholes, damaged roads, garbage, broken streetlights, and water leakage.

Features

- Report civic and road hazards
- GPS location and interactive map
- Dashboard with report statistics
- Search and filter reports
- Update report status
- Optional photo attachment
- JSON export and dark mode

Tech Stack

HTML, CSS, JavaScript, Leaflet.js, OpenStreetMap, and Local Storage.

How to Run

1. Download or clone this repository.
2. Open "index.html" in your browser.
3. Allow location access if required.
